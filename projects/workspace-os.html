THE IDEA

I wanted a single, clean workspace where I can access the tools I use every day without switching between multiple websites. WorkSpace.OS brings these tools and resources together in a minimal and focused interface.

WHAT I BUILT

A web-based workspace with a clean interface, organized toolkit, quick access to important tools and a minimal design that makes it easy to navigate. The layout is built to be simple, aesthetic and focused on productivity.
